## SECTION-BY-SECTION DEVELOPMENT IS MANDATORY

Une seule grande section visuelle par execution.

  SECTION -> PREVIEW -> TEST -> CORRECTION -> USER VALIDATION

Puis seulement, la section suivante.

INTERDIT :
- construire plusieurs grandes sections en une execution sans accord explicite ;
- enchainer automatiquement sur la section suivante.

La validation est EXPLICITE et vient de l'utilisateur. Exemple :

  NAVBAR VALIDEE
  GO HERO

## WORKFLOW PEDAGOGIQUE

L'utilisateur apprend le Front-End. Chaque implementation importante suit :

  CONCEPT -> CODE -> EXPLANATION -> LIVE PREVIEW -> RESPONSIVE TEST
  -> CORRECTION -> VALIDATION -> COMMIT -> NEXT

- JSX utilise      -> expliquer le HTML semantique sous-jacent
- Tailwind utilise -> expliquer le CSS sous-jacent
- Flexbox / Grid   -> expliquer la logique de layout
- React utilise    -> expliquer etat, evenements, JS important

L'IA accelere le developpement. Elle ne remplace pas la comprehension.
